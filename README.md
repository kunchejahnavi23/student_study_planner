# Student Study Planner

A simple web application that helps students organize and manage their study tasks.

## Features

- Add study tasks
- View study tasks
- Simple and easy-to-use interface
- Student-friendly design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` - Creates the structure of the website
- `style.css` - Adds design and styling
- `script.js` - Adds functionality to the website

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding your study tasks.
